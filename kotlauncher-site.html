Kotlauncher

Свой лаунчер Minecraft: любые версии игры, ядро на выбор и менеджер модов с Modrinth и CurseForge — в одном окне.

⬇ Скачать для Windows Как установить

Портативная версия — установка не требуется. Понадобится Java 17+ с adoptium.net.

Что умеет

Всё, что нужно, чтобы играть — без лишних настроек.

📦

Любые версии игры

Список релизов подтягивается прямо с серверов Mojang — от свежих до старых вроде 1.8.9.

⚡

Ядро на выбор

Vanilla, Fabric или NeoForge — плюс выбор конкретной версии ядра под свою версию игры.

🧩

Менеджер модов

Поиск и установка модов с Modrinth и CurseForge. Зависимости ставятся автоматически.

🌙

Тёмная тема

Приятный тёмный интерфейс с фиолетовым акцентом — глаза не устают даже ночью.

👤

Оффлайн-режим

Играй под своим ником без аккаунта Microsoft — просто введи имя и жми «Играть».

⚙️

Настройки памяти

Выдели игре сколько нужно оперативной памяти и укажи свою Java, если хочешь.

Три шага до игры

От скачивания до первого мира — пара минут.

  1. Скачай Kotlauncher-portable-1.0.exe кнопкой выше и запусти — ставить ничего не нужно.
  2. Установи Java 17 или новее, если её ещё нет на компьютере.
  3. Введи ник, выбери версию игры и ядро — и жми большую зелёную кнопку «Играть».

Частые вопросы

Если чего-то не хватает — напиши автору проекта.

Нужен ли аккаунт Minecraft?

Нет — лаунчер работает в оффлайн-режиме под любым ником. Для игры на лицензионных серверах потребуется аккаунт Microsoft.

Нужен ли ключ CurseForge для модов?

Нет. Поиск работает через публичное зеркало без ключа. Свой ключ с console.curseforge.com можно вставить в настройках — как запасной вариант.

Куда ставится игра?

В папку game рядом с exe-файлом. Миры, моды и настройки живут там же — удалять папку не стоит.

Почему Windows может ругаться при запуске?

У самодельных exe без подписи нет цифровой подписи, поэтому SmartScreen может предупредить. Исходный код проекта открыт — нажми «Выполнить в любом случае», если доверяешь автору.
