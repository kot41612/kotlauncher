# 🐱 KotLauncher

**Лаунчер для майкрафт с чёрно-фиолетовой темой — устанавливай моды прямо из лаунчера.**

</div>

---

## ✨ Возможности

- 🎨 **Чёрно-фиолетовая тема** — тёмный интерфейс с фирменной фиолетовой подсветкой
- 📦 **Установка модов из лаунчера** — никаких ручных папок и перетаскивания файлов: ищи и ставь моды в пару кликов
- 🧩 Поддержка модов (укажите: Forge / Fabric / NeoForge / Quilt — оставьте нужное)
- 🚀 Быстрый запуск игры

## 📦 Установка

1. Скачайте последнюю версию со вкладки [Releases]
2. Создайте на любом диске корневую папку и поместите exe файл
3. Выберите версию игры и загрузчик модов — и запускайте

## 🚀 Быстрый старт

1. Запустите KotLauncher
2. Откройте вкладку **Моды**
3. Найдите нужный мод и нажмите **Установить** — мод автоматически попадёт в папку `mods`
4. Запускайте игру 🎮

## 🖥 Системные требования

| Параметр | Минимум |
|---|---|
| ОС | Windows 10 |
| Java | 17+ (для Minecraft 1.17+) |
| ОЗУ | 4 ГБ (рекомендуется 8 ГБ) |
